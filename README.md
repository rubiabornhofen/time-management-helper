## Para repositórios privados

Como gerar o token recomendado:
* Crie um Fine-grained token no GitHub (Developer Settings > Personal access tokens).
* Em Repository access, selecione os repositórios que deseja auditar.
* Na seção Repository permissions, conceda permissão Read-only (apenas leitura) para:
    - Pull requests (Read-only)
    - Metadata (Read-only)
