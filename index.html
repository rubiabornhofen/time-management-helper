Configurar Credenciais

Opcional para repositórios públicos. Necessário para repositórios privados ou para contornar o limite de requisições (rate limit).
Como gerar o token recomendado:
  1. Crie um Fine-grained token no GitHub (Developer Settings > Personal access tokens).
  2. Em Repository access, selecione os repositórios que deseja auditar.
  3. Na seção Repository permissions, conceda permissão Read-only (apenas leitura) para:
    • Pull requests (Read-only)
    • Metadata (Read-only)
